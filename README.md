# 油品价格维护

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 计量温度补偿

在油品价格维护中增加计量温度补偿，按标准升（V₂₀）计价结算：

- 每笔登记：油品、视体积 Vt、油温 t、视密度 ρt、登记标准密度（化验单）。
- 换算依据 GB/T 1885（标准温度 20℃）：
  - VCF = 1 - α × (t - 20)，汽油 α≈0.0012/℃、柴油 α≈0.0008/℃（查表值在 -10~50℃ 的一阶近似，公式与系数在代码注释中可核）。
  - 标准体积 V₂₀ = Vt × VCF；标准密度 ρ₂₀ = ρt / VCF；质量 m = ρt × Vt 守恒核对。
  - 补偿明细（VCF、标准升、ρ₂₀、质量、与档案参考密度偏差 ‰）实时展示、可核。
- 越界处理：油温越过 -10℃ ~ 50℃、视密度越出档案范围、或标准体积超过罐容时，**保留输入**并标记"异常暂停"；暂停与未复核记录均**不进入均价**，复核按钮禁用。
- 结算：按标准升 × 档案挂牌价计价；点"复核确认并冻结"后冻结 VCF、标准升、单价与金额（含复核人、时间），挂牌价后续变动不影响已冻结结算。
- 更正：对已复核记录点"更正"，必须填写更正原因，系统新建原因版本（旧版本保留并标记"已替代"），新版本重新进入待复核；版本明细可展开核对旧值。
- 均价：仅"当前版本已复核且冻结"的记录参与，按标准升加权，分油品与综合两档；刷新后温度、标准升结算、均价与版本均从 localStorage 快照恢复，保持一致。

## 分层（不新增依赖）

```
src/
  archive/masterData.ts          档案层：油品种类、密度/温度/罐容边界、α、挂牌价
  conversion/compensation.ts     换算层：VCF、标准密度、标准升、越界判定（纯函数）
  storage/persistence.ts         存储层：版本化登记、冻结结算、localStorage 读写与种子
  pages/OilPriceMaintenance.vue  页面层：登记/复核/更正/均价/档案维护
```

数据默认保存在浏览器 localStorage（`dfwlfront-9-fuels-v2`、`dfwlfront-9-registrations-v2`），旧版挂牌价键 `dfwlfront-9-price` 保留不删，方便后续扩展接口、权限、图表或地图能力。
