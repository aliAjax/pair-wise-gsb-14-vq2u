# 油品价格维护（计量温度补偿）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia（未新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

每笔登记：油品、挂牌价、视体积 Vt、油温 t、视密度 ρt、标准密度 ρ20、操作员、生效日期。

温度补偿（GB/T 1885 简化模型，质量守恒口径）：

```
γ   = (ρ20 − ρt) / (t − 20)          密度温度系数（g/cm³/℃）
VCF = ρt / ρ20                       体积温度修正系数
V20 = Vt × VCF                       标准体积（标准升）
金额 = V20 × 挂牌价
```

- 油温越过 −10℃ ~ 50℃、视/标准密度越过油品档案区间、反算 γ 异常，或 V20 超过罐容：
  输入全部保留，记录置为「已暂停」并列出原因，**不进入均价**。
- 合格登记为「待复核」，同样**不进均价**；复核确认瞬间冻结 V20、单价、金额与完整补偿明细。
- 结算一律按**标准升**计价，卡片展示逐步换算明细可核。
- 已确认记录更正不覆盖旧值：必填更正原因、新建 v+1 版本；新版本确认后旧版本转为「已更正」，
  旧冻结结算原样保留，只有新版本参与均价。
- 暂停/待复核记录可就地修订，按新录入重新校验。
- 数据整体版本化存入 localStorage（schema v2），刷新后温度、标准升结算、均价、版本一致；
  读到旧版价格页结构自动回退种子数据，不混用。
- 均价 = 已确认记录结算金额合计 ÷ 标准升合计（按标准升加权，元/标准升）。

## 分层（互不耦合，不加依赖）

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 档案 | `src/domain/catalog.ts` | 油品档案、密度区间、罐容、计量温度边界 |
| 换算 | `src/domain/conversion.ts` | γ / VCF / V20 纯函数、越界校验、结算金额 |
| 结算口径 | `src/domain/settlement.ts` | 均价汇总、冻结快照、记录构造 |
| 存储 | `src/storage/records-store.ts` | 版本化序列化、种子数据 |
| 状态 | `src/store/oil-store.ts` | Pinia 用例编排（登记/复核/更正/修订） |
| 页面 | `src/pages/*` | 登记表单（实时补偿试算）、记录卡片、列表页 |

领域层（`src/domain`）与存储、框架无关，可直接用 esbuild/Node 引入做纯函数校验。
